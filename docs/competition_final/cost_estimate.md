| 分类 | 项目 | 当前状态 | 询价/核验内容 |
|---|---|---|---|
| 已有开发资源 | Ubuntu 22.04开发主机、ROS2 Humble、Gazebo、项目代码 | 本次执行环境可观察到；归属项目的设备资产需团队确认 | 是否属于团队、可否现场携带、显卡/CPU/内存与维护成本 |
| 已有设备 | temi机器人 | 当前无实体设备 | 型号、SDK授权、售后、维护、电池和运输费用 |
| 未来采购 | Temi底盘/配件 | 待询价/待确认 | 设备含税价、保修、可用接口和地区供应 |
| 未来采购 | Ubuntu侧计算机 | 待选型/待询价 | 需满足模型推理与ROS负载；规格需按实际模型/相机测试决定 |
| 未来采购 | RGB-D或广角相机/安装件 | Temi内置相机能力尚未核验 | 接口、内参、帧率、视角、同步、固定支架和隐私影响 |
| 未来采购 | 局域网设备与安全急停配件 | 待现场方案 | 覆盖范围、认证、隔离、防火墙与急停流程 |
| 可选扩展 | 后向/全景视觉或额外深度传感器 | 仅作为后续设计选项 | 必须先做视野/遮挡验证，不能默认需要或宣称已具备 |
| 未询价项目 | 场馆测绘、地图制作、安装、人员培训、保险与维护 | 未询价 | 需要场馆范围、部署周期与服务等级后再询价 |

不提供总价或单价结论，避免把估算冒充报价。提交采购预算前由团队获取同一币种、日期、税费口径和供应商书面报价。
