# 初赛五区导览配置

配置文件：`config/submission_exhibits.yaml`、`config/submission_system.yaml`。路线从待命点出发，依次前往非遗概览、传统工艺、代表作品、传承故事、互动体验，随后到出口；互动体验既是第五区也是问答站，不增加重复停靠。地点名对应两套 Gazebo 布局生成的目标。

导览状态机保留原八站格式，并新增对该七站格式的校验。状态机仍需游客明确同意才能开始导航，互动区等待问答结束或超时再前往出口。当前导览词为演示占位内容，需场馆审核。

新增状态机测试验证五区顺序、等待同意、互动后前往出口及两套地图目标映射；原有状态机测试一并通过。配置是业务层准备，现有 Gateway 仍使用 Mock/Android 后端，尚未接入 Gazebo Nav2，不能用此配置直接声称网页和 Gazebo 已完成导览联动。下一步实现 Nav2 适配器和安全取消，再以真实 ROS Action 联动测试。
