# 4.3 Mock 稳定性验证

目标：同一组 Mock ROS2 进程连续多轮完整导览，记录每轮结果；验证运行中 Gateway 退出后异常关停、人工重新启动仍处于待机。仅本机，不能替代实机验证。

方案：沿用现有一键启动程序，增加显式 `--demo --rounds N`；每轮独立验证八站、问答、静止、游客数据与错误计数，记录历史，不自动重试失败。默认仍为待机。故障测试只终止测试自己启动的 Mock 子进程，不接触其他节点。
