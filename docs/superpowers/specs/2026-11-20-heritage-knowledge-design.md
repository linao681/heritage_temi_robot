# 3.1 非遗知识库与离线问答设计

## 范围

建立独立 ROS2 `heritage_knowledge` 包，覆盖现有五个示例展区：潮绣、潮州木雕、潮州工夫茶艺、潮剧、潮州音乐。当前无授权的真实展品资料，不虚构展品、展厅或讲解员审核结果。先使用经核对的官方公开非遗资料形成可追溯的样例知识条目；待展厅工作人员审核后才能用于实际展陈。3.2 再接入 QA 状态和 Mock 播报，真实 ASR/TTS 仍为 HARDWARE_REQUIRED。

## 方案

- 推荐：结构化中文 FAQ 与本地关键词、别名匹配，按展区及问题意图检索并返回来源明确的预写答案。小数据量不依赖网络 API、向量数据库及模型下载；对未知问题明确拒答。限制是同义问法覆盖依赖词表和测试集，不能声称具备开放域生成能力。
- 备选：本地语义嵌入和向量检索。可提高自然问法覆盖，但引入模型运行和检索质量评估成本；资料规模扩大后再考虑。
- 暂不使用联网大语言模型生成答案，避免未经审核的文化史事实、成本和网络依赖。

## 数据与接口

- `config/knowledge.yaml`：每个条目包含唯一 ID、展区 ID、主题、问题意图、别名/关键词、简明和进阶答案，以及来源名称、URL、资料核对日期。答案使用自主概括、不复制长篇文章；在资料不足、来源不符时不生成该条目。加载时校验必填字段、唯一 ID、展区合法性与来源存在性。
- `knowledge_store.py`：加载与验证本地知识库；`qa_engine.py`：中文文本规范化、关键词与意图匹配，优先明确主题/可选展区上下文；冲突、弱匹配或无资料时拒答或要求明确主题，不猜测。只返回已存储事实、条目 ID 和对应来源；支持 basic/advanced 讲解层级。
- 独立 CLI：明确输入文本问题，输出 JSON 或简明中文答复与引用；ROS2 节点提供本地问答服务，定义请求问题、可选展区与层级，响应含是否有根据、答案及来源 JSON。遵循项目已有接口生成方式，不修改已有导航接口或自动控制逻辑。
- 无互联网推理、无游客身份信息、无需实体机器人。输入空白、过长、非法级别或不可用数据时明确报错/拒答；不发导航或播放命令。

## 验收

1. 核对五个主题官方资料与出处，整理每主题不少于三条独立、可证实的问题意图（若资料不足，明确记录缺口而不补造）。
2. 设计独立中文测试集，覆盖常见问题、不同表述、主题冲突、展区上下文、入门/进阶、未知问题及输入异常；记录预期命中和拒答结果。指标只代表该测试集，不冒称开放域准确率。
3. 实际构建新 ROS2 包和接口、执行独立 CLI 与本机 Service 回环，验证返回答案/来源一致且未知问题不产生虚构事实；复跑既有 156 项 Linux 测试及新增测试，保存日志和报告。
4. 更新 README、架构、开发日志和知识库维护说明；3.2 导览 QA 接入及工作人员正式审校仍待后续。
