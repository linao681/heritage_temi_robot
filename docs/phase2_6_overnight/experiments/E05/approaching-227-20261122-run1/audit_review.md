# E05 首轮接近停车复核

原始报告 `report.json` 保持 `FAIL`：移动窗口内没有被融合层判定为有效的人员距离样本。没有覆盖或拼接其他轮次数据。

## 结论：FAIL（目标距离停车未验证）

- Gazebo 真值确认人物只移动 0.232 m，移动窗口约 0.979 s；人物模型在安全停止请求后停止移动。
- 速度控制器于 58438.424 s 因“感知数据无效或过期”请求停车，`input_valid=false`。同一时段 RGB-D 人员距离字段曾有效，约 4.22 m，但融合总状态因稳定游客人数输入失效而被整体标为无效，速度控制未获得该距离。
- Gazebo 真值记录的移动窗口内最小机器人—人物中心距约 4.053 m，按现有包络估算的表面间隙代理值约 3.567 m。该结果不能作为近距离阈值停车证据。
- 停车确认和后续恢复存在于完整事件记录中；导览事件最终完成 `wait → zone_1 → zone_2 → zone_3 → zone_4 → zone_5 → exit`。运行器因缺少有效融合人员距离在最终验收时标记 FAIL。

复核定位到控制输入将稳定人数计数有效性与人员测距有效性耦合：即便 RGB-D 的测距字段有效，访客人数状态暂时无效也会被视为整个运动感知输入无效。代码已拆开来源可信、人员观测有效与人数统计有效，并新增回归测试；后续重试保存在独立目录，不改变本失败记录。这里记录的 fail-closed 停车属于输入有效性保护，不等于 E05 通过。
