# 实体 temi 接入准备清单

状态基于阶段2.8执行时对 Android Kotlin Bridge、ROS gateway 和感知代码的静态审查。没有实体 temi；本清单不代表硬件验收。

## 已有软件接口可复用

| 模块 | 现状 | 接入时核验 |
|---|---|---|
| temi SDK生命周期 | `android/temi_heritage_bridge/.../SdkTemiDriver.kt` 监听 Ready、位置、电量、导航、速度、TTS；注销监听器 | 目标设备 Launcher/SDK版本及授权；首次仅读 Ready/位置/电量 |
| 保存地点导航 | `SdkTemiDriver.goTo` 要求 SDK saved location 命中，不关闭原避障 | 在真实地图建立并核对 wait、五区、出口地点名称和坐标；不可复用 Gazebo 坐标 |
| 停止 | SDK `stopMovement()` 经 `BridgeCoordinator` stop 状态机调用；协调器要求收到导航/零速度终态证据才完成 | 在人工可控空场逐步测停止反馈、延迟、漂移和急停；软件 ACK/CANCELED 不是物理静止认证 |
| 位置和速度 | SDK 原始 `Position` 坐标/velocity 作为遥测；frame 标为 `temi_sdk_unverified` | 实测坐标系、单位、yaw方向、速度符号/单位、更新率和数据新鲜度；通过后固定 frame 变换 |
| 语音播报 | Android `TtsRequest.Language.ZH_CN` 并监听 request 状态 | 测中文发音、音量、打断/取消、完成事件与现场噪声；Mock Speak 不替代实体TTS |
| ROS2↔Android | WebSocket v1，Gson 严格 JSON，握手/状态同步，命令有截止时间/去重ID/导航会话；断线后清会话并请求停止，不重放旧运动 | 在隔离局域网逐项测认证、重连、序号、时钟、证书与网络中断。当前 Android endpoint/credentials 需按部署配置核实，禁止写入仓库 |
| 安全限速 | `TemiSpeedManager` 使用SDK位置变化接口；Bridge协议限制0.3–0.8m/s并带 session id 和 control_reason | 范围是软件参数契约，不代表 Temi 底盘许可或可达档位；先读SDK回调并在空旷环境标定 |
| 视觉感知 | ROS现有 YOLOX RGB、RGB-D深度关联与LaserScan融合可复用 | Temi SDK当前适配层未暴露相机/深度原帧；须确认设备能否合法提供外部摄像头/深度源，安装视角/内参/TF另行标定 |
| 人员匿名跟踪 | 阶段2.8新增 ROS 匿名 bbox 关联和团队观察器，不识别个人身份 | 需要真实相机输入、覆盖测量与隐私告知；前视相机不能自动证明后方成员仍在队伍中 |

## 仍需实体设备或现场确认

- **SDK权限和版本：**按确切 temi 型号、Launcher 版本与批准的 Robot SDK 版本核对签名、设备权限及回调行为；不得把模拟APK连接成功当兼容验收。
- **真实地图：**由场馆建立地图并标入口、每区讲解点、避让区、无障碍路线、出口、充电点；保存地图版本与坐标复核记录。
- **相机/深度：**确认实体提供的图像接口和采样率；标定内参、畸变、RGB-depth同步、相机到base的TF、离地高度和视场。没有后置摄像头时标注后方盲区并安排人工集合确认。
- **LaserScan与障碍层：**确认temi可接入的障碍源、坐标及频率；不宣称SDK导航具备ROS Nav2的具体costmap行为，需通过安全场地观察实际绕障。
- **制动标定：**分档低速直行、确认地面/载荷/电量条件，测指令、SDK速度回调、真实位置/速度和停止距离；重复急停/断线但不关闭原厂安全功能。
- **操作员接管：**定义现场急停人、警戒范围、游客隔离、网络断开、定位丢失、低电量和人工回收步骤；运行前做演练。
- **Android↔ROS部署：**同一受控网络配置静态/可发现主机地址、防火墙、身份认证和TLS；先只读连接，再做不会运动的短命令，最后开放受控导航。
- **ASR语音输入：**当前审查只确认 TTS 接口；未确认项目已有可用 ASR 输入闭环。需设备实测并取得用户同意，未完成前使用清晰的屏幕/按钮交互。
- **停止保障：**确认断线后SDK是否继续运动、自动刹停条件及状态回调延迟；部署前需实测。不以 WebSocket ACK、ROS action cancel 或应用日志作为物理急停证明。

## 首次实体验收顺序

1. 记录设备型号、Launcher/SDK版本、网络和电量；工作人员在旁，实体保持原厂避障与急停能力。
2. 安装已审查 APK，仅确认SDK Ready、saved locations、位置/电量/速度/TTS事件；暂不导航。
3. 核实Android与ROS握手、认证、状态同步和断线保护；断网后确认旧任务不会重放。
4. 在空旷封闭区域确认地图/TF，再以最低允许速度完成单个近点导航和人工停止，实测停稳及停止距离。
5. 逐步测试障碍绕行、定位失效、网络断开、低电量、TTS打断和人工接管；每项单独记录并确认停止。
6. 由场馆负责人检查真实游客动线、消防/无障碍要求、隐私告知和人工监督安排；未通过任一安全项不得用于公众导览。
